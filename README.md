# 🎌 AniStack — Anime & Manga Tracking Platform

AniStack is a full-stack Anime & Manga Tracking Platform that helps users organize, monitor, and manage their anime watching and manga reading progress in one place.

Built using the **MERN Stack**, AniStack integrates with the **Jikan API** to provide rich anime and manga information while offering personalized tracking features and secure authentication.

## ✨ Features

### 📺 Anime Tracking
- Search and discover anime using the Jikan API.
- View detailed anime information:
  - Ratings
  - Genres
  - Popularity Rankings
  - Episode Counts
  - Release Information
- Track anime progress dynamically.
- Categorize anime into:
  - Watching
  - Completed
  - On Hold
  - Planned
- Mark episodes as watched.
- Display remaining episodes and estimated watch duration.

### 📚 Manga Tracking
- Search and discover manga.
- View detailed manga information:
  - Ratings
  - Genres
  - Popularity Rankings
  - Chapter Counts
  - Publication Information
- Track manga reading progress.
- Mark chapters as read.
- Display remaining chapters and estimated reading progress.

### 📊 User Dashboard
- Personalized anime and manga collections.
- Detailed tracking statistics.
- Progress overview across all categories.
- Collection management and organization.

### 🔐 Authentication & Security
- JWT-based Authentication.
- Secure Login & Registration.
- Protected Routes.
- Persistent User Sessions.

### ⚡ Performance Optimizations
- Efficient API handling using asynchronous operations.
- Optimized frontend rendering.
- Responsive UI for multiple devices.
- Faster data loading and smoother user experience.
